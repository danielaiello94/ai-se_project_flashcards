# Flashcard App

My first project in TripleTen's AI-Assisted Software Engineering program. It includes deck of flashcards, each of which can be viewed in a carousel.

## Features

Expandable flash cards used to study for whatever is needed. Flash cards can be added or deleted at need.

## Technologies Used

HTML, CSS, Javascript
